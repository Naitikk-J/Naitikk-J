## About

I build full-stack products at the intersection of interfaces, data, and chains. The work I care about is the kind a campus, a clinic, or a hackathon jury can actually use: a fest site with a 3D map, a campus identity system, a carbon-credit ledger, a pharmacy finder for 2 a.m.

Code Coalescence winner for **Reconnect Hub**. HackSagon '25 finalist with **CRX**. HackSagon '26 finalist with **TrackMate**. Smart India Hackathon participant.

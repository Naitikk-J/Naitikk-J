| | |

<details>
<summary><b>🛰️ &nbsp; TrackMate — Decentralised Civic Safety Platform &nbsp;·&nbsp; <i>HackSagon 2026 Finalist · SIH</i></b></summary>

<br/>

> A **4-role civic-safety platform** (Tourist · Resident · Business · Authority) with **sub-50ms geofencing**, an **offline-first Ghost-Queue SOS**, and a **Gemini-powered risk-forecasting engine**.

| | |
| :--- | :--- |
| **Stack** | React · Node.js · Socket.IO · Flutter · Gemini API · Solidity · Hardhat · MongoDB |
| **Scale** | 4 role-based dashboards + native mobile app · designed for city-wide load |
| **Performance** | **Sub-50 ms** geofence resolution · Service-Worker Ghost-Queue for offline SOS |
| **Security** | Solidity smart contracts for tamper-proof **E-FIR** logging · role-based auth |
| **Impact** | Selected as **HackSagon 2026 Finalist** · SIH Travel & Tourism track shortlist |
| **Repository** | [github.com/Naitikk-J](https://github.com/Naitikk-J?tab=repositories) |

Designed around the assumption that **connectivity fails first in a real emergency**. Ghost-Queue replays queued SOS packets the moment the device comes back online, while the on-chain E-FIR ensures no authority can silently rewrite an incident log after the fact.

</details>

<details>
<summary><b>🪪 &nbsp; MITS Smart ID-Card Management System</b></summary>

<br/>

> A full-stack **hostel operating system** — gate access, attendance, library issue, election voting and admin reporting — driven by **AES-256 encrypted QR ID cards**.

| | |
| :--- | :--- |
| **Stack** | Node.js · Express · React 19 · Flutter/React Native · MongoDB · Redis · Socket.IO · Docker |
| **Scale** | Designed for **entire hostel** — students, wardens, guards, admins |
| **Performance** | Real-time Socket.IO admin feed · Redis-backed JWT with token blacklisting |
| **Security** | **AES-256** QR encryption · **RBAC** (SUPER_ADMIN → Security Guard) · GPS geofence |
| **Impact** | Replaces paper log-books, biometric queues and separate attendance apps |
| **Repository** | [github.com/Naitikk-J](https://github.com/Naitikk-J?tab=repositories) |

The most fun engineering constraint was the **guard-side mobile scanner** — it had to work in poor network, print offline-signed audit rows, and *never* let a revoked card slip through. Redis blacklist + short-lived JWTs + AES-256 QR payloads made that possible without a chatty backend.

</details>
